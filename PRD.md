# Quantitative Portfolio Optimization Dashboard

## Project Scope
A Python, Streamlit, and Scikit-learn dashboard that handles historical financial data pipelines, modern portfolio optimization (MPT), and predictive returns estimation.

## Tech Stack
- Data Frameworks: Python, Pandas, NumPy, SQL / SQLite
- Machine Learning & Optimization: Scikit-learn, SciPy
- Frontend UI: Streamlit, Plotly

## Rules
- Avoid monolithic code blocks; separate concerns across modular scripts.
- Use explicit Type Hinting across functions.
- Write a matching unit test file for any computational engine built.
